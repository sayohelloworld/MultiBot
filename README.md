## 🛠️ Auto-hébergement & Installation

💻 Basé sur Node.js & Discord.js v14, vous pouvez cloner et héberger votre propre instance de MultiBot très facilement.
📥 Clonage & Dépendances :

git clone https://github.com
cd MultiBot
npm install

⚙️ Configuration (config.js) :

module.exports = {
    token: "YOUR_DISCORD_TOKEN",
    clientId: "YOUR_CLIENT_ID",
    prefix: "+",
    embedColor: "#49ff02",
    ownerId: "YOUR_DISCORD_ID",
    supportServerInvite: "https://discord.gg"
};

🚀 Lancement :

node index.js

🌐 Hébergement 24h/24 recommandé : Railway, Render, Replit ou VPS (OVHcloud, Hetzner, DigitalOcean).
